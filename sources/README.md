# Sources and receipts

Every public factual figure should resolve to a `SRC-###` record containing:

- publisher and title;
- stable URL or public identifier;
- publication and last-checked dates;
- region and units;
- licence / republication terms;
- collection or calculation method;
- confidence (`confirmed`, `estimate`, `derived`, `scenario`, or `needs refresh`);
- refresh cadence;
- corrections or limitations;
- sector (`sector`, the register's last column): the slug of the sector dossier the figure belongs to — `food`, `water`, `shelter`, `energy`, `healthcare`, `care`, `education`, `transportation`, `clothing`, `goods`, `materials`, `communication`, `safety`, `environment` or `leisure` — or empty when the figure is not one sector's cost (governance, wealth and ownership, all-items CPI). A figure card with a sector shows a SECTOR chip linking that dossier; the site build fails on any value that is not one of those slugs.

The control plan is registered for governance provenance, not as evidence for a public cost figure. The initial cost-source library has not yet been reviewed or published.
